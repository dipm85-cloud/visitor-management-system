# Settings Ownership Map

Application Settings is the central settings front door. Existing specialist and legacy panels remain reachable through Application Settings until their controls are safely migrated.

| Settings area | Current location | Target location | Status | Migration risk | Future milestone | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| General | Application Settings -> General | Application Settings -> General | Native | Low | OHP-017C | Controlled registry values stay native in Application Settings. |
| Branding | Application Settings with legacy fallback | Application Settings -> Branding | Mostly native | Medium | OHP-017C.2 | Application Settings owns commercial branding, shell/theme, logos, favicon, print-logo and contrast defaults; legacy remains a fallback during rollout. |
| Modules | Application Settings -> Modules | Application Settings -> Modules | Native | Low | OHP-017D | Single visible module configuration entry point; duplicate Administration -> Module Configuration nav item removed. |
| Visitors | Visitors workspace, legacy VMS settings and Form Requirements | Application Settings -> Modules -> Visitors | Partially migrated | High | OHP-017D | Visitor settings and Form Requirements are surfaced from Application Settings; complex visitor workflows remain unchanged. |
| Shared Terminal | Application Settings plus Shared Terminals device administration | Application Settings -> Modules -> Shared Terminal | Partially migrated | Medium | OHP-017D | Terminal display/reset settings are native; device/token administration remains linked. |
| Documents / Sign-off | Application Settings plus Document Sign-offs administration | Application Settings -> Documents / Sign-off | Partially migrated | High | OHP-017E | Safe document defaults are native, including identity-linked compliance, canonical context, print logo, evidence detail and locked future scroll control; document type/version/evidence workflows remain linked. |
| Privacy / Data Governance | Application Settings plus Privacy / Data Governance administration | Application Settings -> Privacy / Data Governance | Partially migrated | High | OHP-017E | Privacy defaults are native, with locked anonymisation guardrails; case, SAR, evidence, anonymisation and search workflows remain linked. |
| Identity Resolution | Identity Resolution administration | Application Settings -> Modules -> Identity Resolution | Linked | Medium | OHP-017D | Module card links to review requests, candidate queues, confirmed links and decision history. |
| People & Assignments | Application Settings -> People & Assignments | Application Settings -> Modules -> People & Assignments | Partially migrated | Medium | OHP-017D | Assignment Form Requirements are native; wider people-policy settings remain future work. |
| Working Time | Reference Data working-time entities | Application Settings -> Modules -> Working Time | Linked | High | OHP-017D | Module card opens existing Work Time Profiles, Break Rules, Unsociable Rules and rota-related links without changing calculation logic. |
| Session Security | Access Control -> Online Users / System Messages | Application Settings -> Session Security | Linked | Medium | TBD | Open the existing Session Security settings card without changing timeout behaviour. |
| Notifications | Application Settings plus Access Control -> Online Users / System Messages | Application Settings -> Notifications | Partially migrated | Medium | OHP-017E | Message type, expiry, required-action grace, force-after-grace default, online window and history row defaults are native; send/history workflows remain linked. |
| Access Control / Diagnostics | Application Settings plus Administration -> Access Control | Application Settings -> Access Control / Diagnostics | Partially migrated | Medium | OHP-017E | Diagnostics defaults and locked Capability Inspector status are native; role presets, user assignments and effective capability workspaces remain linked. |
| Future LMT | Not available | Application Settings -> Modules -> Future LMT | Future | Low | Future | LMT settings will be configured here after the LMT module foundation is added; no runtime behaviour in OHP-017E. |
