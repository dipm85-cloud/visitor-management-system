# Settings Ownership Map

Application Settings is the central settings front door. Existing specialist and legacy panels remain reachable through Application Settings until their controls are safely migrated.

| Settings area | Current location | Target location | Status | Migration risk | Future milestone | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| General | Application Settings -> General | Application Settings -> General | Native | Low | OHP-017C | Controlled registry values stay native in Application Settings. |
| Branding | Application Settings with legacy fallback | Application Settings -> Branding | Partially migrated | Medium | OHP-017C.2 | Application Settings owns commercial branding values and applies shell, subtle gradients, logo, favicon, print-logo, controlled branded text contrast, public-screen background and radius tokens; theme colour reset preserves logos while legacy branding remains fallback during rollout. |
| Modules | Application Settings -> Modules | Application Settings -> Modules | Native | Low | OHP-017D | Application Settings -> Modules is the single visible module configuration entry point; the duplicate Administration -> Module Configuration nav item was removed. |
| Visitors | Visitors workspace, legacy VMS settings and Form Requirements | Application Settings -> Modules -> Visitors | Partially migrated | High | OHP-017D | Module card opens visitor settings, Planned Visit requirements, Walk-in requirements and Shared Terminal links without changing visitor flow logic. |
| Shared Terminal | Application Settings plus Shared Terminals device administration | Application Settings -> Modules -> Shared Terminal | Partially migrated | Medium | OHP-017D | Module card owns terminal display/reset entry points and links to public branding plus device/token administration. |
| Documents / Sign-off | Document Sign-offs administration and legacy agreement settings | Application Settings -> Modules -> Documents / Sign-off | Linked | High | OHP-017D | Module card links to existing document sign-off and agreement settings; specialist panels remain source of truth. |
| Privacy / Data Governance | Privacy / Data Governance administration | Application Settings -> Modules -> Privacy / Data Governance | Linked | High | OHP-017D | Module card links to privacy cases, GDPR workflows, SAR evidence and audit/governance tools. |
| Identity Resolution | Identity Resolution administration | Application Settings -> Modules -> Identity Resolution | Linked | Medium | OHP-017D | Module card links to review requests, candidate queues, confirmed links and decision history. |
| People & Assignments | Application Settings -> People & Assignments | Application Settings -> Modules -> People & Assignments | Partially migrated | Medium | OHP-017D | Module card opens Assignment Form Requirements and keeps wider people-policy settings linked for future migration. |
| Working Time | Reference Data working-time entities | Application Settings -> Modules -> Working Time | Linked | High | OHP-017D | Module card opens existing Work Time Profiles, Break Rules, Unsociable Rules and rota-related links without changing calculation logic. |
| Session Security | Access Control -> Online Users / System Messages | Application Settings -> Session Security | Linked | Medium | TBD | Open the existing Session Security settings card without changing timeout behaviour. |
| Notifications | Access Control -> Online Users / System Messages | Application Settings -> Modules -> Notifications / System Messages | Linked | Medium | OHP-017D | Module card opens Online Users, System Messages, Message History and Required Actions. |

| Future LMT | Not available | Application Settings -> Modules -> Future LMT | Future | Low | Future | LMT settings will be configured here after the LMT module foundation is added; no runtime behaviour in OHP-017D. |
